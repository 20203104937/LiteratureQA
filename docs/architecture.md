# 模块与边界

所有代码按“输入 → 检索 → 证据 → 回答”分工。文件名是职责名称，不表示不同部署服务。

| 文件 | 输入与输出 | 责任 |
|---|---|---|
| `schema.py` | 论文、片段、证据记录 | 约束字段、校验摘要位置、读取 JSONL |
| `ingest.py` | Markdown/PDF → 论文 JSONL | 解析摘要位置，调用外部解析器，成功后替换语料 |
| `retrieval.py` | 问题、论文 → 排名与正文片段 | 关键词、可选向量检索、倒数排名融合 |
| `settings.py` | TOML 配置与环境变量 → 参数 | 公共配置、角色覆盖、参数校验 |
| `prompts.py` | 角色与数据 → 系统指令和 JSON 输入 | 每个角色仅接收自己需要的材料 |
| `client.py` | 提示词 → 模型响应与调用记录 | 并发门限、超时、有限重试和真实用量 |
| `pipeline.py` | 问题 → 回答、证据和筛选记录 | 调度四种任务，检查原文，执行双阈值规则 |
| `service.py` | 语料与配置 → 每次请求的处理实例 | 共享只读检索索引，每次创建独立模型客户端 |
| `cli.py` | 命令行 → 导入、问答或检索评测结果 | 保存结果，关键失败返回退出码 2 |
| `api.py`、`ui.py` | 网页问题 → API 结果 → 展示 | 本机服务，引用原文和错误信息展示 |
| `demo.py` | 虚构文献 → 演示结果 | 固定规则，明确区分真实模型 |
| `metrics.py` | 论文 ID 集合或耗时 → 指标 | 明确指标分母，拒绝空的标准相关集 |

TOML 是配置文件格式，用 `[章节]` 和 `名称 = 值` 表示参数。环境变量是进程启动时读取的配置值，适合提供无需写进源码的密钥。

## 关键词分数

对问题中每一个不同词 `t`，文献 `d` 的贡献为：

```text
IDF(t) = ln[1 + (N − df(t) + 0.5)/(df(t) + 0.5)]
词的贡献 = IDF(t) × f(t,d) × (k1+1)
          / {f(t,d) + k1 × [1−b+b×文献长度/平均文献长度]}
文献分数 = 所有问题词的贡献之和
```

`N` 是文献数；`df(t)` 是出现过该词的文献数；`f(t,d)` 是词在当前文献的出现次数；`ln` 是自然对数。`IDF` 是 Inverse Document Frequency，即逆文档频率，用来让少见词获得较大权重。`k1=1.5` 控制词频增长后的收益递减；`b=0.75` 控制长度调整程度。摘要索引同时包含标题；正文索引以每个字符片段为一篇检索文档。

中文的单字与双字会同时计入词频，所以索引中的“长度”是分词后的项目数，不等于原文字符数。分词、排序并列规则和公式固定，方便用同一份输入重复检查。

## 任务依赖和失败

角色拆分成功后，各子问题执行检索；各论文必须先提取证据，再评分。摘要评分全部返回后才计算阈值；正文复查完成后才汇总最终证据。论文门限在等待模型时仍占用，但不会再向同一论文门限递交子任务，容量为 1 时也能完成。

真实模型接口用 Python 标准库发请求，在异步流程中交给工作线程等待网络。异步表示某个任务等待期间允许别的任务推进。语义编码也交给工作线程；共享嵌入模型用锁保护，同一时刻只编码一批，因此启用更多论文任务不意味着模型编码也会成倍并行。

网络失败、超时、HTTP 408/429 及部分服务器错误允许有限重试；默认最多两次尝试，等待 1 秒后重试。一次 HTTP 成功但 JSON 或证据不合法时不重试，也不补造结果。失败文本不记录密钥或供应商响应正文。HTTP 是网页和接口交换请求的协议，429 通常表示服务要求降低请求频率。

问题拆分或最终汇总失败，整次问答标记 `failed`。单篇论文提取或评分失败，该论文被排除，并在 `errors` 中保留失败记录。没有可用证据则明确返回 `insufficient_evidence`。调用记录中 `success=true` 只表示接口返回有效聊天文本；结构化格式和引用检查结果应结合 `errors` 阅读。

输出中的 `duration_seconds` 包含本次问答拆分、检索、网络等待、重试和汇总时间，但不包含服务启动、模型加载和语料导入。调用排队耗时单独记录，因此不能简单把每次接口耗时相加当作整次请求耗时。

## 当前实现边界

- 全文和关键词索引读入内存，适合先验证个人语料；不提供大型文献库的磁盘索引或增量更新。
- PDF 解析是外部工具适配，测试使用模拟解析器，识别质量仍需人工检查。
- 语义检索受嵌入模型输入长度限制；代码不会把较长文本分词后重新拼成无限长向量，模型可能截断输入。
- 只验证引用原文存在和编号合法，未使用独立事实核查器证明每个生成结论。
- 不提供集群调度、本地生成模型服务、付费问答评测结果或自动抓取版权文献。
- 可选网页和语义模型依赖应分别安装；离线测试不访问外网或发送真实模型请求。
